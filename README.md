# Personal Portfolio

A responsive one-page portfolio built with only HTML5 and CSS3.


## Technologies
- HTML5 (semantic tags, accessible form)
- CSS3 (variables, Flexbox, Grid, media queries, transitions, keyframes)
- Git and GitHub Pages

## Features
- Sticky header with smooth-scrolling anchor links
- Sections: Hero, About, Skills, Projects, Contact, Footer
- Mobile-first responsive layout tested at 375px and 1280px
- Dark mode that follows the system setting, hero fade-in animation

## What I learned
Writing this by hand taught me how the box model and `box-sizing` shape every layout,
and when to reach for Flexbox (one direction) versus Grid (two directions).
The hardest part was making the layout feel balanced on both phone and laptop widths.
Committing every day and validating my HTML with the W3C validator built good habits.
